## Getting Started

### Prerequisites
- Node.js 18+

### Installation
```bash
git clone https://github.com/waliahmad-blip/Noorish.git
cd Noorish
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
